# TypTap — тренажёр слепой печати

Статическое веб-приложение без сборки и без npm: один `index.html`
плюс рантайм рядом с ним. Уроки, адаптивные тренировки, статистика,
16 мини-игр и таблица лидеров.

## Где хранится прогресс

**Целиком в браузере, в `localStorage`** — ключ `typtap_v2`. Никакого
сервера, никакой регистрации и паролей: вход по нику просто выбирает
профиль внутри этого же браузера.

```js
localStorage['typtap_v2'] = {
  current: 'Maria',           // активный ник
  profiles: {
    Maria: {
      sessions: [...],        // история заходов: wpm, точность, ошибки по клавишам
      completed: {...},       // пройденные уроки
      streak: { count, last },
      bestRace: 0,            // рекорды мини-игр
      xp: 0
    }
  }
}
```

Из этого следует:

- профиль **не переносится** между устройствами и браузерами;
- очистка данных сайта (или режим инкогнито) стирает прогресс;
- приложение полностью работает офлайн — сетевых запросов оно не делает.

Таблица лидеров — локальный демонстрационный список (`_lbSeed()` в
`index.html`), в него подмешивается ваш собственный результат. Настоящего
глобального рейтинга без сервера быть не может.

## Что где лежит

```
index.html          — приложение целиком (разметка + логика)
support.js          — рантайм, нужен рядом с index.html
Mascot.dc.html      — подкомпонент маскота
```

## Запуск локально

Просто откройте `index.html` в браузере. Если браузер ругается на
ограничения `file://`, поднимите любой статический сервер из папки проекта:

```bash
python -m http.server 8000     # затем http://localhost:8000
```

## Словари, источники данных и использование AI

**Словари уроков.** Наборы слов — это вручную составленные списки частотных
коротких слов для каждого языка (`en` / `uk` / `ru`), встроены прямо в
`index.html`, объект `LANGDATA` (поля `words`, `sents`, `pro`). Внешние
словари/корпуса **не импортировались**: списки собраны вручную из
общеупотребительной лексики, предложения написаны специально для тренажёра.
Раскладки рядов (`home`/`top`/`bottom`) — стандартные QWERTY и ЙЦУКЕН.

- **Источник:** оригинальная компиляция авторами TypTap.
- **Очистка:** только строчные буквы, без пунктуации в базовых уровнях;
  слова появляются лишь после того, как все нужные буквы «открыты» курсом
  (уровни ряды → слова → предложения → скорость).
- **Лицензия данных:** т.к. сторонние словари не используются, лицензионных
  обязательств третьих сторон нет; списки распространяются под лицензией
  проекта (см. `LICENSE`).
- **Атрибуция:** отдельная атрибуция не требуется.

**Адаптивная тренировка** подбирает слова по вашим слабым клавишам
(`_weakKeys()` — агрегирование ошибок последних сессий); это статистика ваших
промахов, а не внешние частотные таблицы.

**Использование AI.** В рантайме AI/ML **не используется**: приложение
работает полностью офлайн, без внешних API и секретных ключей. Опциональный
бэкенд синхронизации (`backend/`) — это обычный Node.js + PostgreSQL, тоже без
AI. Маскот и графика — оригинальные (инлайновый SVG).

**Данные и приватность.** Хранится только ник и прогресс: локально в
`localStorage` и, если развёрнут бэкенд, в вашей БД. Пароли/почта/иные
персональные данные не собираются.

## Алгоритм упражнений (кратко)

- **Прогрессия по клавишам:** буквы вводятся по рядам (домашний → верхний →
  нижний → цифры → пунктуация → Shift), слова появляются только после того,
  как все нужные символы «открыты».
- **Биграммы и триграммы:** уровень «Слова й біграми» использует частотные
  пары/тройки (`LANGDATA[lang].bigrams` / `trigrams`) вперемешку со словами.
- **Адаптивность:** тренировка подбирает слова по вашим слабым клавишам
  (частотность ваших ошибок за последние сессии).
- **Приоритет точности и ритма:** урок засчитывается пройденным только при
  точности ≥ 80 %; в результатах показывается метрика **ритма**
  (ровность интервалов между нажатиями), а не только скорость.
- **Свой текст:** экран «Свій текст» принимает вставленный текст или файл
  **.txt / .md** (проверка расширения и размера ≤ 100 КБ, очистка от
  управляющих символов, лимит 5000 знаков) и превращает его в упражнение.

## Доступность

Поддержка `prefers-reduced-motion` (анимации отключаются), видимый фокус
(`:focus-visible`), навигация карточек с клавиатуры (Enter/Space), ARIA-роли
(навигация, диалоги, список лидеров) и `aria-live` для смены раскладки.
